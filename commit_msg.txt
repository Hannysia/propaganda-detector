Refactor data pipeline: static splitting, HF integration, and env cleanup

This commit overhauls the data processing pipeline to ensure reproducibility, integrates Hugging Face Datasets, and decouples environment setup from training logic.

Changes:

1. Data Preparation (ETL):
   - Converted parser into a full ETL script (parser.py) with ideal seed search.
   - Implemented static assignment of Folds (0-4) and Holdout flags directly into the dataset.
   - Automated upload of the processed dataset to Hugging Face.

2. Training Pipeline (src/train.py):
   - Removed dynamic splitting logic; now loads pre-split data directly from HF using datasets.
   - Added source_dataset_repo argument for flexibility.
   - Replaced setup_environment call with direct os.getenv("HF_TOKEN") usage.

3. Utils & Environment (src/utils/...):
   - Removed setup_environment function. Authentication (HF, W&B) and configuration are now handled via environment variables, making the script platform-agnostic (Kaggle/Local/Cloud).

4. Dataset Class (src/data/dataset.py):
   - Added **kwargs support to PropagandaDataset for tokenizer arguments.
